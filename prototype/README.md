# Планер — приложение для Windows и Mac

## Что нужно
- Node.js (LTS) с https://nodejs.org

## Запуск
Положите `index.html`, `main.js`, `package.json` в одну папку, откройте в ней терминал и выполните:

```
npm install --save-dev electron electron-builder
npm start
```

## Сборка установщика
- Windows (на компьютере с Windows): `npm run build:win` → установщик `.exe` в папке `dist/`
- Mac (на компьютере с macOS): `npm run build:mac` → файл `.dmg` в папке `dist/`

Собирать версию для Mac можно только на Mac.

## Где хранятся данные
Локально на компьютере (в папке данных приложения). Для резервной копии или переноса
на другой компьютер используйте кнопки «Экспорт» / «Импорт» внизу боковой панели.

## Горячие клавиши
- Ctrl/⌘ + N — новая страница
- Ctrl/⌘ + K — поиск
- «- » в начале строки заметки — маркированный список
