## 1. Что мы делаем

Десктопное приложение для **Windows и macOS**: простой планировщик задач и заметок в духе Notion / «Заметок» iOS.
Главное — **удобный, чистый и быстрый интерфейс** для организации пространства (страницы) и задач.

- Язык интерфейса: **русский**.
- Работает **полностью офлайн**, данные хранятся локально на компьютере.
- Без аккаунтов, без серверов, без облака (пока).

## 2. Что уже есть

В папке `prototype/` лежит рабочий прототип. **Возьми его за основу**, не переписывай с нуля без причины:

- `prototype/index.html` — весь интерфейс и логика (HTML + CSS + чистый JS, без фреймворков). Данные пока хранятся в `localStorage`.
- `prototype/main.js` — минимальный главный процесс Electron.
- `prototype/package.json` — скрипты и настройки electron-builder.
- `prototype/README.md` — инструкция по запуску.

Что уже умеет прототип:
- Дерево страниц и подстраниц в боковой панели (создать, удалить, свернуть/развернуть), поиск по страницам.
- У страницы: эмодзи-иконка (выбор из набора), заголовок, заметки (contenteditable, «- » в начале строки делает список).
- Задачи на странице: чекбокс, текст, срок (дата), приоритет (высокий / средний / низкий), удаление.
- Два вида задач: **Список** и **Доска** (Kanban: «Сделать» / «В работе» / «Готово», перетаскивание мышью).
- Раздел **«Сегодня»** (просроченные, сегодня, ближайшие 7 дней) и **«Все задачи»**.
- Светлая и тёмная тема, экспорт и импорт JSON, горячие клавиши Ctrl/⌘+N и Ctrl/⌘+K.
- Свои модальные окна вместо `confirm`/`alert`.

## 3. Стек и правила

- **Electron** + **electron-builder**. Интерфейс: чистый HTML/CSS/JS, **без React и других фреймворков** (приложение должно оставаться простым).
- Можно разбить `index.html` на несколько файлов (`index.html`, `styles.css`, `app.js` и т.п.), если так удобнее.
- **Никаких CDN и внешних загрузок**: всё должно работать без интернета.
- Безопасность Electron: `contextIsolation: true`, `nodeIntegration: false`, доступ к файлам только через `preload.js` + IPC.
- Код и комментарии понятные; UI-тексты на русском.
- Я работаю на **Windows**. Пиши команды для PowerShell / cmd.

Целевая структура:

## 4. Этапы работы

### Этап 1. Каркас проекта
1. Проверь, что установлены Node.js (LTS) и git. Если нет — скажи мне, что установить, и остановись.
2. `git init`, создай `.gitignore` (`node_modules/`, `dist/`, `out/`).
3. Создай `package.json` (на основе `prototype/package.json`), установи `electron` и `electron-builder` как devDependencies.
4. Перенеси прототип в `src/` по структуре выше.
5. `npm start` должен открывать окно с работающим приложением.

**Готово, когда:** приложение запускается через `npm start` и выглядит/работает так же, как прототип.

### Этап 2. Надёжное хранение данных
1. Замени `localStorage` на файл **`data.json`** в папке `app.getPath('userData')`.
2. Чтение и запись — через `preload.js` (`window.api.load()`, `window.api.save(data)`) и IPC.
3. Запись **атомарная**: сначала во временный файл, потом переименование. Сохранение с задержкой (debounce ~300 мс) и обязательно при закрытии окна.
4. **Резервные копии:** раз в день копировать `data.json` в `backups/data-ГГГГ-ММ-ДД.json`, хранить последние 14.
5. Если файл повреждён — не терять данные: попробовать последнюю резервную копию и показать мне сообщение.
6. Миграция: если `data.json` ещё нет, а в `localStorage` есть данные прототипа, перенести их.
7. Добавь в данные поле `version: 1` для будущих миграций.

**Готово, когда:** данные переживают перезапуск приложения, а файл и резервные копии видны в папке userData.

### Этап 3. Нормальное окно и меню
1. Запоминать размер и положение окна между запусками.
2. Меню приложения на русском: Файл (Новая страница, Экспорт, Импорт, Выход), Правка (Отменить, Повторить, Вырезать, Копировать, Вставить, Выделить всё — **обязательно**, иначе на Mac не работает копирование), Вид (Тема, Масштаб, Полноэкранный режим), Справка (О программе).
3. Запуск только одной копии приложения (`requestSingleInstanceLock`).
4. На macOS: аккуратный заголовок окна (`titleBarStyle: 'hiddenInset'`) с отступом в боковой панели под «светофор».
5. Экспорт и импорт через системные диалоги (`dialog.showSaveDialog` / `showOpenDialog`), а не через ссылку на скачивание.

### Этап 4. Улучшения интерфейса и задач
Делай по порядку; после каждого пункта проверяй, что ничего не сломалось.
1. **Время у задачи** (необязательное поле) и **напоминания**: системное уведомление в нужное время (Electron `Notification`). Клик по уведомлению открывает нужную страницу.
2. **Подзадачи** или описание у задачи: клик по задаче открывает боковую панель с деталями (описание, подзадачи-чекбоксы, срок, приоритет, страница).
3. **Перетаскивание страниц** в боковой панели (изменить порядок и вложенность).
4. **Отмена удаления**: после удаления задачи или страницы показывать всплывашку «Удалено · Отменить» на 5 секунд.
5. **Избранное**: закрепление страниц сверху боковой панели.
6. **Поиск по задачам** тоже, а не только по страницам (Ctrl/⌘+K открывает быстрый поиск-палитру).
7. Мелочи: сворачиваемая боковая панель (Ctrl/⌘+\), пустые состояния с подсказками, плавные анимации без перегруза.

Сохраняй стиль прототипа: светлый тёплый фон, акцентный цвет `#d9643a`, много воздуха, системный шрифт.

### Этап 5. Иконка и сборка
1. Сделай простую иконку приложения (SVG → PNG 1024×1024, `build/icon.png`; electron-builder сам сделает .ico и .icns).
2. Настрой electron-builder:
   - Windows: установщик NSIS (`.exe`), с выбором папки установки и ярлыком на рабочем столе.
   - macOS: `.dmg`, архитектура `universal` (Intel + Apple Silicon).
   - Название: «Планер», `appId: uz.planer.app`.
3. Собери версию для Windows: `npm run build:win` → проверь, что установщик в `dist/` ставится и приложение запускается.
4. **Версия для Mac:** собрать на Windows нельзя. Сделай GitHub Actions workflow (`.github/workflows/build.yml`), который собирает Windows- и Mac-версии на `windows-latest` и `macos-latest` по тегу `v*` и прикладывает файлы к релизу. Объясни мне, как его запустить.
5. Предупреди меня, что без подписи кода Windows SmartScreen и macOS Gatekeeper покажут предупреждение, и как его обойти при установке.

### Этап 6. Проверка и документация
Пройди вручную по чек-листу и отчитайся:
- [ ] Создать страницу, подстраницу, переименовать, сменить иконку, удалить (и отменить удаление).
- [ ] Заметки сохраняются, списки через «- » работают.
- [ ] Задачи: добавить, отметить, срок, приоритет, время и напоминание приходит.
- [ ] Доска: перетаскивание между колонками.
- [ ] «Сегодня» и «Все задачи» показывают правильные задачи.
- [ ] Перезапуск приложения — всё на месте; резервная копия создаётся.
- [ ] Экспорт → импорт возвращает те же данные.
- [ ] Тёмная тема, горячие клавиши, копирование/вставка работают.
- [ ] Установщик Windows ставится и запускается.
